# 🎯 Mastermind Game

A responsive digital implementation of the classic **Mastermind** code-breaking game, built using **HTML, CSS, and JavaScript**.

The game challenges the player to crack a hidden color combination within a limited number of attempts using logical deduction and feedback from previous guesses.

## ✨ Features

* 🎨 Six available colors for code generation
* 🔐 Secret code consisting of four colors
* 🚫 No duplicate colors in the secret code
* 🎯 Limited number of attempts
* 💡 Feedback-based deduction system
* 🔄 Dynamic code generation for every game
* 📊 Attempt tracking and scoring
* 💭 Hint functionality
* 🏆 Win and loss conditions
* 📱 Responsive and interactive interface
* 🔁 Option to restart and play again

## 🛠️ Technologies Used

* **HTML5** – Structure and game interface
* **CSS3** – Styling, layout, animations, and responsiveness
* **JavaScript** – Game logic, code generation, validation, feedback, scoring, and state management

## 🎮 How to Play

1. Start a new game.
2. A secret combination of four colors is generated.
3. Select four colors to create your guess.
4. Submit your guess to receive feedback.
5. Use the feedback to logically determine the hidden combination.
6. Continue making guesses until you crack the code or run out of attempts.

## 🧠 Game Logic

The game uses JavaScript to:

* Generate a random secret combination.
* Validate each player guess.
* Compare the guess with the secret code.
* Provide feedback based on correct colors and positions.
* Track the number of attempts.
* Calculate the player's score.
* Determine win or loss conditions.
